# ICE 409 offline study app

Download **ICE_409_Study.html** using GitHub's **Download raw file** button. Open the saved HTML file in Chrome, Edge, Firefox, or Safari. GitHub's source-code page does not run the app.

The updated app contains:

- All text, tables, diagrams, original practice questions, answers, source notes, and quick review from the 55-page **ICE_409_Reviewer.pdf**.
- A **Complete PDF content** reader with search across all 14 sections.
- The exact original 55-page PDF embedded in the HTML; use **Save original 55-page PDF** to download it without internet access.
- **180 multiple-choice practice questions**, 20 per topic: 5 remembering, 5 understanding, and 10 application questions per topic. Choices are shuffled and every question includes a rationale.
- **180 flashcards**, nine written application cases, a searchable question library, and locally saved progress with JSON backup/restore.

The HTML is a single self-contained file with no external asset or service dependencies. Some mobile file-preview apps do not execute HTML; use a full browser, preferably on a computer. A local HTTP server is an optional alternative if your browser restricts local-file behavior.

Download the updated HTML again to receive the new content. Keep it in the same location/browser if you want existing local progress to remain accessible. Storage behavior varies by browser; export a backup before replacing/moving files or clearing browser data. Existing question IDs were retained in this update.

## Source limits

ASME and ISO content is supplemental background because the six uploaded lectures did not substantively cover those two exam-pointer topics. The app preserves the reviewer's source warnings and corrections. New quiz questions are study exercises, not an official exam or predictions. Coverage/accuracy indicators and card self-ratings do not certify exam readiness or engineering competence.

The complete reader reproduces the **55-page reviewer**, not the separate 376-page preserved lecture-source appendix. Original chapter practices, integrated cases and the worked lecture quiz key are retained in that reader; they are distinct from the expanded 180-item interactive question bank.
